为什么选择「图提取」？

解决电商运营与设计师在采集素材时的三大核心痛点

🔍 懒加载图片难抓取

电商详情页大量采用动态滚动懒加载与 CSS 背景图，普通右键无法直接保存，本插件深度扫描 DOM 属性一键提取。

🖼️ WebP/AVIF 格式不兼容

网页直接保存下来的图片往往是 `.webp` 格式，无法直接拖入旧版 PS。插件内置 Canvas 引擎自动转换为标准 `.png`。

⚡ 逐张保存效率低下

几十张商品主图与详情切片，手动保存耗时费力。集中画廊预览，支持全选、反选并按 `商品图_001.png` 自动编号保存。

六大核心功能

🚀

一键提取

点击右下角悬浮按钮，自动扫描页面所有商品图，完美兼容各类懒加载属性。

🛡️

智能过滤

自动排除页面内的按钮图标、店铺 Logo、占位图以及小于 100×100 的碎图。

🎛️

集中预览

在独立的新标签页网格化展示所有提取到的高清图片，并直观标注真实像素尺寸。

☑️

自由勾选

支持点击卡片单选、一键全选、一键反选，实时显示已选数量，按需精准下载。

🎨

统一 PNG

无论原图是 JPG 还是 WebP，下载时底层自动重绘转换为无损 PNG 格式。

📥

批量下载

一键批量保存到浏览器默认下载目录，自动按 `商品图_001.png` 规则整齐编号。

四步极速安装指南

1

下载并解压源码

从 GitHub 仓库下载插件压缩包，并在本地电脑解压到一个固定文件夹。

2

打开扩展管理页

打开 Chrome 浏览器，在顶部地址栏输入 chrome://extensions 并按回车。

3

开启开发者模式

在扩展程序页面右上角，找到并打开「开发者模式」开关。

4

加载已解压的扩展

点击左上角「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹即可。
